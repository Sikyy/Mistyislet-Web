# Mistyislet Website Documentation

This folder is the planning source of truth for rebuilding the current Framer "Message" template as the Mistyislet public website.

## Documents

- [Product Brief](./product-brief.md)
  Defines what Mistyislet is, who the website speaks to, and which claims are safe to make from the product codebase.
- [Framer Template Blueprint](./framer-template-blueprint.md)
  Captures the current Framer page, template, component, and variant hierarchy so the coded website can mirror the structure.
- [Content Specification](./content-spec.md)
  Lists the final site copy section by section.
- [Implementation Specification](./implementation-spec.md)
  Converts the Framer structure into engineering requirements for the future code implementation.
- [Development Plan](./development-plan.md)
  Breaks the implementation into executable phases, expected files, QA checks, and launch criteria.

## Current Scope

The first website version is a single-page marketing site with anchored navigation:

1. Product
2. Solutions
3. Resources
4. Partners
5. Pricing

The primary CTA text is `Preview` across the site.
